# Quick Reference - Nexora AI Workflow Email System

## 🚀 Start Here

```bash
cd c:\Users\sqavi\Nexora-ai
streamlit run app.py
```

Open: **http://localhost:8502**

---

## 📧 Send Email in 3 Steps

### **Step 1: Open Workflow Generator**
Click **⚙️ AI Workflow Generator** in sidebar

### **Step 2: Type Your Request**
Examples:
```
Send email to syeduddin827@gmail.com that tomorrow is holiday

Email admin@company.com about system maintenance tomorrow

Remind syeduddin827@gmail.com about the 3 PM meeting
```

### **Step 3: Generate & Execute**
1. Click **"🚀 Generate Workflow"**
2. Review the workflow
3. Click **"💾 Save Workflow"**
4. Go to **🎮 Controls**
5. Run the workflow

✅ Done! Email is sent!

## ❓ Common Issues

| Problem | Solution |
|---------|----------|
| Email not received | Check email address is correct, verify in `.env` |
| Workflow not generating | Simpler prompt, check internet connection |
| Email looks wrong | Generated correctly, check your email display |
| Multiple recipients | Mention both emails: "Email A@gmail.com and B@gmail.com" |
